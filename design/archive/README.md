# design/archive/ — historical working notes

These are the project's working notes as they were written: per-milestone
implementation plans, roadmaps, gallery parity audits, and retrospectives.
They contain point-in-time statuses, internal task language, and instructions
between the project owner and the implementer — nothing here is current
documentation, and much of it is deliberately self-critical (that's what
working notes are for).

They are preserved unedited because the CHANGELOG and the `[Dnn]` decision
log cross-reference them, and because the development history is part of the
record. For the current state of the project, see [`design/`](../README.md)
and the docs site.
