> **Input.** With waves 1.1–1.5 shipped and the gallery metric exhausted
> (`roadmap-post-rerun.md` §0), the owner directed a review of the API and
> underlying interface itself: *now that we know what functionality is
> possible, is there a better design — easier for outside developers who

> one root: **the abstraction stops one level short on both sides**.

> is private with no external users ([D64]), so deprecation shims serve
> nobody; examples/tests migrate in the same waves. Both sides of the

> to confirm at review, alternatives recorded. *(Reviewed and approved

> changed between this proposal and the shipped result.)*

## 0. Architectural read — where the abstraction stops short

**Internal.** "Compute in core, draw everywhere" ([D67]/[D110]) produces
bare numpy tuples that each backend re-transliterates into the same
drawing recipe. The evidence is concrete:

- `render_quiver` exists three times (`pyqtgraph/_renderers.py:627`,
  `matplotlib/_renderers.py:648`, `webengine/_figure.py:616`) — the same
  recipe (two NaN-gapped polylines from `resolved_segments()`, themed
  color, width/alpha, draw both) in three dialects. `render_streamlines`
  is a near-verbatim copy of `render_quiver` *within* both native
  backends.
- Contour inline labels ([D117]) are core-placed once, then the drawing
  (mask segment + rotated text) is re-encoded three times, with
  per-engine angle-sign conventions re-stated each time.
- The `HONORED` honesty tables are maintained in triplicate
  (`pyqtgraph/_renderers.py:1175`, `matplotlib/_renderers.py:986`,
  `webengine/_figure.py:766`); **78 of 81 rows are byte-identical**.
- Adding an element costs ~17 files / ~300 lines (measured on
  Streamlines `46510b4`, Stem `acb6846`, Quiver `fe9a662`), of which
  ~160 lines are registration and bookkeeping.
- Three data-consumption regimes coexist (channel-resolved tabular, raw
  gridded reach-through, data-less annotations), held together by
  `getattr(node, "data", None)` and `object.__setattr__` side-channels
  (`data/pipeline.py:89`).

**External.** 28 elements with **four** channel-naming conventions
(`x=/y=`, `column=`, `values=/labels=`, positional arrays);
`label`/`labels`/`cell_labels`/`bar_labels` carrying four meanings;
`norm` vs `color_norm`; `scale=` meaning rasterization on Scatter but
axis transform on AxisSpec; `alpha`/`line_width` unevenly present; and
the Overlay-for-a-title tax — `Overlay([el],
options=OverlayOptions(title=…))` appears **16 times in our own
examples**. The `.opts()` sugar was pre-approved in
`axis-surface-feasibility.md` §2.2 and never shipped; `.with_()` appears
in zero docs and zero examples.

**The completion.** One typed intermediate representation closes both
gaps:

```
Element → resolve (data) → lower (core: geometry + encoding → typed Marks) → draw (backend mark adapters)
```

A small **Mark vocabulary** (~8 frozen types) becomes the contract
between core and backends. Tail elements ship as *one core `lower()` +
zero backend edits*. Honesty becomes **structural** — an option is
honored iff it demonstrably survives into the marks, provable by a
perturbation guard test, which retires the triplicated tables. And
because every lowered element is now "channels + style groups that lower
to marks", the public vocabulary can finally be made uniform and *kept*
uniform by construction. Fast-path elements keep hand-tuned native
renderers as registry overrides that win over lowering — the fast
backend stays fast.

**Invariants kept, untouched.** Elements pure/immutable/Qt-free/
value-hashed; backends registered never imported; negotiation pure; one
Element one meaning; honor-or-warn never-raise ([D51]); curated
vocabulary ([D54] — no `register_element`); no live objects on Elements
([D53]/[D58]); 100% offline ([D37]); the `*`/`+` algebra; "a small
surface you can hold in your head". This is the same library with the
seams straightened.

## 2. Part A — the Mark IR

### The vocabulary

New module `core/marks.py`. Eight mark types cover the tail of the 28
elements. All frozen dataclasses, Qt-free, numpy-carrying; ndarray
fields force `eq=False` plus an explicit `structurally_equal(a, b)`
helper (`np.array_equal` per array field) — deliberately *not* `__eq__`,
so marks never masquerade as value-hashed objects.

| Mark | Draws | Consumed by (examples) |
|---|---|---|
| `Polyline` | NaN-gapped line(s); `connect="finite"\|"pairs"`; optional step/baseline-fill | Quiver, Streamlines, Stem stalks, ErrorBars whiskers, Ecdf, contour lines |
| `Markers` | point set; scalar or per-point size/color; `pickable` flag | Stem heads, BoxPlot outliers |
| `Band` | fill between two curves, either orientation | Spread, Area, Violin bodies |
| `Rects` | axis-aligned rectangle set | Histogram, Bars, BoxPlot boxes |
| `PolygonMark` | closed outline(s) + fill | Rect, Ellipse, Polygon annotations |
| `TextMark` | positioned text; rotation; optional line-mask | contour labels ([D117]), heatmap cell labels ([D113]), Text |
| `Rule` | infinite h/v/sloped line | HLine, VLine, RefLine |
| `SpanMark` | shaded h/v region | Span |
| `ArrowMark` | point-to-point connector, **engine-native** screen-space heads (wave-2 addition — heads must not zoom, unlike Quiver's data-space barbs) | Arrow |

Style rides on two small structs — `Stroke(color, width, dash, alpha)`
and `Fill(color, alpha)` — carrying **resolved** `Color` (theme and
palette slot already applied during lowering). Resolved-not-symbolic is
what makes honesty checkable: "the option survived into the mark" is
only decidable if the mark records the outcome. Cost: lowering output is
theme-dependent, so it is recomputed per render — which is exactly when
today's `resolved_*()` methods run anyway.

`RasterMark` is deliberately absent from v1: Image/Heatmap/Mesh stay
native; adding it later is additive.

### [D121] Marks are linear data space; log is an adapter concern

**Decision (proposed).** Mark positions are always linear data space (or
axes-fraction where flagged, e.g. anchored text). No log pretransform in
marks. The pyqtgraph adapter applies `logify` at draw time — precisely
what `render_quiver`/`render_stem` do today — while matplotlib/webengine
let their axes transform do it. Angles are CCW degrees ([D96]);
per-engine sign flips (today re-encoded per renderer for contour labels)
move into the adapters, stated once each. Consequence: `x_scale`/
`y_scale` stop leaking above the adapter layer, and `RenderContext`
sheds a backend implementation detail.

**Alternatives weighed.** Pre-transformed marks (couples lowering to a
per-backend concern, breaks "one lowering, three drawings"); dual-space
marks with a flag (complexity without a consumer).

### [D122] Lowering is an Element method

**Decision (proposed).**

```python
# core/lowering.py
@dataclass(frozen=True)
class LowerContext:
    theme: Theme
    series_index: int = 0
    show_legend: bool = True
    # deliberately NO scales, NO viewport, NO parent — lowering is pure & data-space

@dataclass(frozen=True, eq=False)
class Lowered:
    marks: tuple[Mark, ...]
    legend: LegendEntry | Legend | None = None    # [D60]/[D112] flow through here
    select_xy: tuple[np.ndarray, np.ndarray] | None = None   # brush registration

class Element:
    def lower(self, ctx: LowerContext) -> Lowered | None:
        return None    # None ⇒ no lowering; a backend must have a native renderer
```

`type(el).lower is not Element.lower` is the dispatch predicate that
feeds `supports()`. The existing `resolved_segments()`/`resolved_labels()`
adapters become private helpers of `lower()` or fold in. Lowering runs
on *resolved* elements inside `backend.render()`/`handle.update()` —
never per frame; the `resolve_node` pipeline and the [D77] streaming
fast path are untouched. No caching in v1 (lowering cost ≈ today's
`resolved_*()` cost, and streaming fingerprints would defeat a cache
exactly where it might matter); revisit only if the update-path
benchmark regresses.

The entire cross-backend Quiver implementation, after:

```python
class Quiver(Element):
    HONORED_BY_LOWERING = frozenset({"color", "alpha", "line_width", "label",
                                     "arrow_scale", "head_scale", "key", "key_label"})
    def lower(self, ctx):
        (sx, sy), (hx, hy) = self._segments()
        stroke = Stroke(resolve_color(self.color, ctx.theme, ctx.series_index),
                        width=self.line_width, alpha=self.alpha)
        return Lowered(marks=(Polyline(sx, sy, stroke), Polyline(hx, hy, stroke)),
                       legend=self.legend_entry(ctx.theme, ctx.series_index))
```

**Alternatives weighed.** A core lowering registry
(`core/lowering.py: dict[type, fn]`) — splits an element's meaning
across two files again and doubles the new-element touch count; rejected.

### Backend mark adapters and dispatch precedence

Per backend, one new `_marks.py`: `MARK_DRAWERS: dict[type[Mark],
Callable[[Mark, RenderContext], Any]]` (~8 functions, 8–20 lines each,
written once ever) plus one generic `render_lowered(element, ctx)` that
lowers, dispatches each mark, registers legend/selection. Dispatch:

```python
def _renderer_for(self, element):
    fn = self.renderers.get(type(element))          # native / fast-path override WINS
    if fn is not None: return fn
    if type(element).lower is not Element.lower:    # element lowers
        return render_lowered
    return None                                     # unsupported → negotiation routes away
```

On webengine a mark maps to a `TraceOp` — `("trace"|"shape"|"annotation",
dict)` — folded into the figure dict. This **deletes the 9-type
isinstance ladder** at `webengine/_figure.py:1008–1029`; annotations
stop having a second dispatch mechanism. Datashader is unaffected:
`resolve_node` still turns a huge Scatter into an `Image` before the
backend sees it, and Image is native everywhere.

**Element tiers.**

| Tier | Elements |
|---|---|
| **Fully lowered (14)** | Quiver, Streamlines, Stem, Spread, Ecdf, HLine, VLine, Span, Text, Arrow, Rect, Ellipse, Polygon, RefLine |
| **Hybrid (0 — dissolved by the wave-3 amendments below)** | — |
| **Native (14)** | Scatter · Curve · Image · Mesh · Pie · RawFigure · ErrorBars (wave-2 amendment) · **wave-3 amendments:** Histogram, Bars, Area, BoxPlot, Violin, Heatmap, Contour — the stats/raster family's numbers are already computed once in core ([D67]/[D93]/[D105]); what remains per backend is engine bar/fill idioms, log-baseline conventions, category-axis ticks, and engine contouring (`ax.contour`) whose geometry a core lowering would visibly change. The IR's honesty machinery still applies to them through the per-backend HONORED tables (now small); revisit individual elements only with evidence the duplication hurts. |

### [D123] Honesty is declared next to the lowering and proven by perturbation

**Decision (proposed).** Each lowered element declares
`HONORED_BY_LOWERING: frozenset[str]` beside its `lower()` — one
declaration, in core. A **tier-1 guard test** (no Qt) makes it honest
mechanically: for every element × every `RECOMMENDED_OPTIONS` entry,
build with the option at a non-default value (reuse `_NON_DEFAULT` from
`test_backend_conformance.py`), lower both, and assert

```
opt ∈ HONORED_BY_LOWERING  ⟺  not structurally_equal(marks_default, marks_perturbed)
```

An option is honored **iff it survives into the marks** — silent drops
(the project's #1 diagnosed weakness, root cause R4) become impossible
for lowered elements, not merely warned-about. The three ~35-line
`HONORED` dicts are deleted; what remains per backend is a small native
table (~6 rows) plus the three real deltas (pg Contour − `filled`, pg
Image − `interpolation`; Pie-absent-on-pg stays a `supports()` fact). A
mark type a backend cannot draw is a registration-time error (guard:
every backend's `MARK_DRAWERS` is total over `MARK_TYPES`) — never a
silent drop. `core/_degrade.py` is untouched; only its feeding tables
change. False-negative closure (an adapter dropping a Stroke field) is
covered by per-adapter field-reaches-native tests (~1 per mark per
backend).

**Alternatives weighed.** Pure runtime derivation (lower twice inside
`honored_options()` — non-pure, slow, and surprising); keeping the
triplicated tables with a sync test (the status quo this retires).

### [D124] One data contract

**Decision (proposed).** `Element.data: DataRef | None = None` on the
base class (annotations get `None` explicitly — every
`getattr(node, "data", None)` becomes `node.data`); class attribute
`DATA_KIND: Literal["tabular", "gridded", "none"]` drives `resolve_node`
and `node_is_lazy` instead of duck-typing; gridded elements gain one
accessor `resolved_grid() -> GridView` replacing scattered
`element.data.grid().values` reaches. The `object.__setattr__`
side-channels (`_raster_source`, `_raster_agg`, `_grid_source`,
`data/pipeline.py:89–120`) become a declared, typed slot —
`Element.aux: RasterAux | GridAux | None`, excluded from value-hashing,
installed via a `_with_aux()` copy in the `_replace_data` style. Same
lifecycle; typed, greppable, un-misspellable.

**Pickability declared, not isinstance'd.** `Lowered.select_xy` and
`Markers.pickable` drive brush/hover wiring for lowered elements;
native elements implement `Element.select_xy() -> (x, y) | None`
(Scatter/Curve; time axes go through `as_float_seconds` inside it,
[D94]). The hardcoded `isinstance(element, (Scatter, Curve, Stem))`
tuples at `pyqtgraph/_events.py:63` and `matplotlib/_events.py:93` are
deleted.

### [D125] Backend protocol 2.0 + entry-point discovery

**Decision (proposed).** Fold the de-facto protocol into the declared
one: `honored_options()`, `requires_display`, the widened
`export(fmt, path, *, dpi=None, transparent=False)`, and the new
`mark_drawers` mapping. Replace `backends/__init__.py::_autoregister`'s
hardcoded try/except list with entry-point discovery
(`[project.entry-points."qtviz.backends"]`; the three built-ins declare
theirs; explicit `register()` stays for tests/embedding). Core still
never imports a backend — invariant 2 finally matches the code.

### [D126] Curve and Bars final tier — decided post-benchmark

Curve defaults native (streaming perf, `marker_every`/step fast paths);
Bars defaults hybrid. Wave-4 benchmarks settle both; whichever way they
land, the decision is recorded here at review time.

### [D127] Pie on pyqtgraph — owner call

`PolygonMark` wedges would make Pie lowered-everywhere and reverse
[D90]'s pg absence. Default: keep absent (a pie in a fast-native
dashboard context remains questionable). Flag for owner preference.

### [D128] Streaming through lowering — deferred

`set_element_data` → relower → mark-item `setData` would extend the
[D77] fast path to lowered elements. Deferred: today those elements
already take the rebuild fallback, and wave-4 benchmarks will show
whether it matters. Current semantics preserved exactly.

> **Shipped 2026-08-06 (post-2.0):** exactly the sketched shape, on
> pyqtgraph — `render_lowered` registers a relower entry per data-carrying
> element (the raster-controller registry pattern); `set_element_data`
> relowers with the streamed arrays and writes Polyline/Markers/Band
> geometry in place, all-or-nothing with the rebuild fallback intact.
> Ecdf/Spread/Stem/Quiver ride it; benchmarked at the native path's 25 ms
> frame ceiling. matplotlib/webengine deliberately keep their fallbacks.

## 3. Part B — the public surface 2.0

### [D129] One channel-binding convention

**The rule (one sentence, teachable):** *`data` comes first; every data
binding is a keyword accessor from a fixed 10-role vocabulary; gridded
elements pass the array(s) as `data`, placed by `extent=` or coordinate
vectors; annotations/shapes stay positional because they bind no data.*

| Role | Meaning | Used by |
|---|---|---|
| `x`, `y` | position channels | Scatter, Curve, Bars, Area, ErrorBars, Spread, Stem, Quiver, Heatmap; coordinate vectors on Mesh |
| `z` | aggregated/color value | Heatmap |
| `u`, `v` | vector components | Quiver, Streamlines |
| `value` | column a statistic is computed over | Histogram, Ecdf, BoxPlot, Violin, Pie |
| `by` | categorical partition (series split / group / slice) | Bars, Area, BoxPlot, Violin, Pie |
| `lo`, `hi` | interval edges | Spread |
| `err` | symmetric or `(lo, hi)` error | ErrorBars |

Renames: `column→value` (Histogram, Ecdf, BoxPlot, Violin — Violin also
gets an explicit signature, retiring `*args, **kw`), `values/labels→
value/by` (Pie), `group→by` (Bars, Area), `bounds→extent` (Image,
Contour, Streamlines — the plotting-standard term; "bounds" reads as
widget geometry in a Qt library), `x_edges/y_edges→x/y` (Mesh: length
N+1 = edges, length N = centers, pcolormesh semantics). Streamlines
becomes data-first and structurally identical to Quiver:
`Streamlines({"u": U, "v": V}, extent=…, u="u", v="v")` — the only
element with two positional data arrays disappears. Spread collapses six
mutually-constrained optionals to `x|y + lo/hi` (exactly one of `x`/`y`
picks orientation).

**Alternative to confirm at review:** spatial `x=` instead of `value=`
for Histogram/Ecdf (more matplotlib-familiar, but splits the stat family
across two conventions and leaves Pie unfixable — `value=`/`by=`
uniform is recommended).

### [D130] One `norm=` spec

`norm: Literal["linear","log","symlog","power","boundary"] | Norm` plus
`clim: tuple[float, float] | None` replace the 5-parameter cluster
(`norm/vmin/vmax/gamma/linthresh/levels`) copy-pasted across
Image/Mesh/Heatmap *and* Scatter's `color_norm`. New public type
`Norm(kind, *, gamma=1.0, linthresh=1.0, levels=None)` carries only the
transform's own parameters; the string shorthand covers the 90% case.
Transform (norm) and range (clim) are different concerns and get
different homes. Net: −15 parameters across 4 elements, +1 small type.

### [D131] One labeling rule; `scale=` freed

- `label=` — legend string. Only meaning, everywhere.
- `by=` — data-bound category names (they are channels).
- `annotate=` — mark annotation, replacing `bar_labels`, `cell_labels`,
  Contour's `labels`: `False` (default) | `True` (value with theme
  formatting) | format-spec string (`".1f"`) | accessor (tabular
  elements). Per-element union spec to be one-pager'd so honor-or-warn
  boundaries are explicit ([D136]).
- `raster=` — rasterization strategy (was Scatter/Curve `scale=`);
  `scale` now exists only on `AxisSpec`, where it means axis transform.

### [D132] Style groups, uniform because structural

Five groups — stroke, fill, marker, colormap, legend — carried by an
element iff its marks carry them (the IR enforces it): `alpha` on every
visible element (added to Bars, Heatmap, Image, ErrorBars, Mesh,
Contour); `line_width=1.5` uniform (Quiver 1.0→1.5 — a visual change,
CHANGELOG'd); one 10-name marker vocabulary (`circle square triangle
triangle_down diamond cross plus star pentagon hexagon`, honor-or-warn
per backend); `axis="y2"` extended from Scatter/Curve to all tabular xy
elements. Style stays **flat kwargs** — no Style object: per-element
IDE completion, and the IR (not a surface object) is what enforces
uniformity; a Style object is what you add when you *can't* enforce
structurally. Backend-specific leaks removed outright:
`pyqtgraph_use_opengl` (deprecated, never wired), `matplotlib_rasterized`.

### [D133] `.opts()` — configure without abandoning the algebra

Per the pre-approved shape (`axis-surface-feasibility.md` §2.2 option 2;
the per-element surface field stays rejected):

```python
Element.opts(*, title=UNSET, x=UNSET, y=UNSET, y2=UNSET,   # x/y/y2: str | AxisSpec
             aspect=UNSET, legend=UNSET, background=UNSET, grid=UNSET) -> Overlay
```

- `Element.opts(**kw)` → `Overlay((self,), options=OverlayOptions(**kw))`
  — pure sugar, no new node type, immutability/value-hashing untouched.
- `Overlay.opts(**kw)` → copy with **field-wise merged** options
  (`UNSET` sentinel so `background=None` can mean "clear"); chains,
  later wins per field; a bare `str` for `x/y/y2` merges into `.label`,
  an `AxisSpec` replaces whole.
- `Layout.opts(**kw)` — same verb, layout fields (`title` = suptitle,
  `link_x`, `link_y`, `rows`, `cols`, `spacing`, ratios, `tab_labels`).
- Unknown kwargs **raise** at construction: a config typo is a
  programming error; honor-or-warn stays reserved for genuine backend
  capability gaps.
- `OverlayOptions.x_label/y_label` removed — the `str | AxisSpec` union
  is the one shorthand, `AxisSpec.label` the one home.
- `legend: bool` + `legend_position: str` merge into one field
  `legend: bool | Literal["auto","right","top","none"] = "auto"`.
- Overlay/Layout reprs list non-default option fields, making
  configuration inspectable.

`OverlayOptions`/`LayoutOptions`/`AxisSpec` survive under their names as
the canonical containers; docs teach `.opts()` first.

### [D134] App layer

```python
qv.show(node, *, title=None, size=(960, 640), backend="auto",
        theme=None, block=True) -> View
```

Creates `QApplication` if absent, wraps in `View`, sizes/titles/shows,
`block=True` runs `exec()`; returns the View in both modes. Kills the
hand-written Qt ceremony in 35/37 examples; `View` stays a plain QWidget
for real apps. Plus `View.on(event_type, cb, *, source=Element|id|list,
throttle_ms=None)` — replaces the `e.source_id == el.id` lambda-filter
idiom — and `qv.set_default_theme(theme)` for symmetry with
`set_default_backend`.

### [D135] Namespace 2.0 — flat, pruned, frozen as `FROZEN_2_0`

Flat stays: ~70 recognizable names *is* the organization. Removed from
`__all__` (still importable from submodules): `negotiate`,
`auto_negotiate` (internal, never user-called), `Accessor`,
`Expression`, `ColorSpec` (typing aliases), `StreamRef`, `DMapBinding`
(return types). Added: `Norm`, `show`, `set_default_theme`. Net
74 → ~70. `test_api_freeze.py` flips to `FROZEN_2_0` in wave 5, so the
freeze certifies the finished surface; CHANGELOG carries a rename table
(mechanical) and a behavior-change table (semantic).

### [D136] Small ratifications (bundled owner calls)

1. `bounds→extent` (recommended) vs keep `bounds` (saves ~8 example
   files of churn).
2. `clim=(lo, hi)` tuple mirroring `AxisSpec.lim` (recommended) vs
   folding vmin/vmax into `Norm`.
3. `annotate=` exact per-element union — one-page spec before wave 3.
4. `show(block=True)` returning the View (recommended) vs returning
   `exec()`'s int.
5. [D129] alternative: `value=` for the whole stat family (recommended)
   vs spatial `x=` for Histogram/Ecdf.
6. [D127]: Pie on pyqtgraph via wedges, or keep absent (default).

## 4. Before → after (the worst pain points)

```python
# hello world -------------------------------------------------------------
app = QApplication.instance() or QApplication([])          # BEFORE (14 lines)
view = qv.View(qv.Scatter(d, x="x", y="y"))
view.resize(720, 520); view.setWindowTitle("hello"); view.show()
raise SystemExit(app.exec())

qv.show(qv.Scatter(d, x="x", y="y"), title="hello")        # AFTER

# titled single element (16 example sites) --------------------------------
qv.Overlay([qv.Curve(d, x="t", y="v")],                    # BEFORE
           options=qv.OverlayOptions(title="Voltage", x_label="t [s]",
                                     y=qv.AxisSpec(scale="log")))
qv.Curve(d, x="t", y="v").opts(title="Voltage", x="t [s]", # AFTER
                               y=qv.AxisSpec(scale="log"))

# dual axis ---------------------------------------------------------------
(qv.Curve(d, x="t", y="temp") * qv.Curve(d, x="t", y="rpm", axis="y2")
   ).opts(y="Temp", y2="RPM")

# mosaic with a suptitle --------------------------------------------------
qv.Layout.mosaic("AAB;CCB", A=a, B=b, C=c).opts(title="Dashboard", link_x=True)

# one channel convention --------------------------------------------------
qv.Histogram(df, value="mass", bins=40)                    # was column=
qv.Pie(df, value="sales", by="region")                     # was values=/labels=
qv.Streamlines({"u": U, "v": V}, extent=(0, 1, 0, 1))      # was Streamlines(U, V, bounds=)
qv.Spread(df, x="t", lo="p5", hi="p95")                    # was 6 optional accessors

# one norm spec -----------------------------------------------------------
qv.Image(Z, extent=b, norm="log")                          # 90% case
qv.Image(Z, extent=b, norm=qv.Norm("symlog", linthresh=0.1), clim=(1e-3, 1))
qv.Scatter(df, x="x", y="y", color_by="v", norm="log", raster="datashader")
```

## 5. Risks and guard tests

| Risk | Mitigation / guard |
|---|---|
| **pyqtgraph per-frame perf** (top risk) | Lowering runs at render/update only; [D77] streaming path untouched. Benchmarks: streaming update allocates no marks; 10k-arrow Quiver render budget (lowering cost ≈ today's `resolved_*()`). |
| Visual regressions in waves 2–3 | Temporary migration gate: offscreen `QWidget.grab()` pixel-diff old-vs-new on affected gallery examples (~1% tolerance), deleted after each wave. |
| Legend parity drift | Everything routes through `legend_entry()`/`Lowered.legend`; the pg custom legend keeps consuming the same `LegendEntry` objects. |
| Webengine hover/pick fidelity | Audit per element before deleting its trace builder; wave-2 elements have minimal hover today. |
| Honesty false-negatives | Total-drawer guard (every backend draws every mark type) + per-adapter field-reaches-native tests. |
| `_degrade` warn-once keyed off constructor defaults | Element `__init__` signatures stay stable through waves 2–3; the [D129] renames land in wave 1 *before* lowering touches those elements. |

## 6. Deliberately not proposed

No `register_element` ([D54] stands); no Style object; no grouped
namespace; no layout DSL; no locator/formatter callables at the seam
(anti-declarative, per `roadmap-post-audit.md` §5); no reopening of the
[D58] non-goals; polar ([D119]) remains its own gate, orthogonal to this
arc — though a lowered world makes Option B (polar as a core transform)
*cheaper*, since a transform over marks is one function, not three
renderer patches.

## 8. Shipped — reconciliation (2026-08-04, qtviz 2.0.0)

All six waves shipped in order, each landing green on the full gate set
(suite, mypy, ruff, strict docs, benchmarks). The deltas between this
proposal and the shipped result, so the corpus stays honest:

1. **Tier census moved during implementation — 14 lowered / 14 native**
   (proposal: 19/6+3 hybrid). Reading the renderer bodies showed the
   proposal was optimistic about the stats/raster family: **ErrorBars**
   (wave 2) and **Histogram, Bars, Area, BoxPlot, Violin, Heatmap, Contour**
   (wave 3) stay native — their *numbers* were already core-computed
   ([D67]/[D93]/[D105]); the per-backend remainder is engine idioms
   (bar gaps, log-baseline conventions, category-axis ticks, Plotly
   stackgroup/box hover, `ax.contour` line geometry) that a forced lowering
   would visibly change. **Ecdf and Spread lowered cleanly** (post-step
   Polyline; Band). The hybrid tier dissolved.
2. **`ArrowMark` joined the vocabulary (9 types)** — annotation arrowheads
   are deliberately screen-space; the mark pins the geometry, each adapter
   draws its engine's arrow primitive.
3. **[D123] honesty landed exactly as designed**, with one addition: the
   perturbation guard runs on *resolved* elements (it caught role/column
   divergence on Spread) and exempts `axis` — honored by surface routing
   (the y2 host), invisible to lowering by construction.
4. **[D125]** shipped with a stale-metadata fallback (a working checkout
   never loses backends when entry points are missing).
5. **[D126] settled by benchmark**: Curve and Bars stay native; ceilings
   pass unchanged post-IR. **[D127]**: Pie stays absent on pyqtgraph
   (default kept).
6. **[D133] final form**: `legend` is one union field
   (`bool | "auto" | "right" | "top" | "none"`), `legend_position` removed
   (kept as a derived internal property); `x_label`/`y_label` removed.
7. **[D135] final count: 70 names** (proposal said ~70). `Norm` was
   exported at [D130] time (wave 3) rather than wave 5 — tests and docs
   needed it; the freeze list moved in the same commit, per policy.
8. **[D136] resolutions**: `bounds→extent` ratified (shipped);
   `clim=(lo, hi)` tuple ratified, accepting `None` halves for one-sided
   clamps; `annotate=` union shipped as `bool | fmt-str` — the *accessor*
   arm (Bars annotating from a column) remains open for a future minor;
   `show(block=)` returns the View in both modes (shipped).
9. **`handle.native()` types changed for shapes** (one Polygon patch /
   svg-path from shared geometry) — non-contractual per `docs/stability.md`,
   noted in the CHANGELOG.
